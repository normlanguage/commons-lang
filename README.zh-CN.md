# Apache Commons Lang

[English](README.md) | [简体中文](README.zh-CN.md)

适配声明与可运行入口位于 `commons/lang`，固定 Apache Commons Lang 3.20.0，发布坐标为 `commons:lang:1`。独立 NAR 消费示例见 [Java Commons Lang](https://github.com/normlanguage/examples/tree/main/java-commons-lang)。完整 census 与未支持原因位于 NAR 的 `binding/java-api.json`。
