# Apache Commons Lang

[English](README.md) | [简体中文](README.zh-CN.md)

The adapter declaration and runnable entry point are in `commons/lang`. It pins Apache Commons Lang 3.20.0 and defines its package coordinates in [module.norm](commons/lang/module.norm). The complete API census and reasons for unsupported APIs are in the NAR's `binding/java-api.json`.

[Runnable samples](samples/README.md) demonstrate the library as an external Norm dependency.
